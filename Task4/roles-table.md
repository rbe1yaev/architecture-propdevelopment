| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| **cluster-admin** | `*` (все операции: create, get, list, watch, update, patch, delete) на всех ресурсах (`*`), включая secrets, namespaces, nodes. Полный доступ ко всему кластеру. | Специалист по ИБ (1 на всю компанию), Технический директор (CTO) — привилегированная группа, доступ к secrets. |
| **security-admin** | `get`, `list`, `watch` для secrets, pods, nodes, namespaces, serviceaccounts, clusterroles, clusterrolebindings, roles, rolebindings, events, pods/log, configmaps. Просмотр секретов и аудит RBAC-конфигураций во всём кластере. | Специалист по ИБ (повседневная роль) — привилегированная группа с правом просмотра secrets без права изменения. |
| **devops-engineer** | `create`, `update`, `patch`, `delete`, `get`, `list`, `watch` для pods, pods/log, pods/exec, pods/portforward, deployments, replicasets, daemonsets, statefulsets, services, endpoints, configmaps, ingresses, persistentvolumeclaims, jobs, cronjobs, horizontalpodautoscalers, events. `get`, `list`, `watch` для namespaces. **Без доступа к secrets.** | DevOps-инженеры всех доменов (по одному на домен: Продажи, ЖКУ, Финансы, Дата) — группа настройки кластера. |
| **developer-readonly** | `get`, `list`, `watch` для pods, pods/log, deployments, replicasets, daemonsets, statefulsets, services, endpoints, configmaps, persistentvolumeclaims, ingresses, jobs, cronjobs, horizontalpodautoscalers, events, namespaces. Только чтение, без права изменений. | Разработчики, бизнес-аналитики, владельцы продуктов, инженеры по эксплуатации (все домены) — группа только на просмотр ресурсов кластера. |
| **domain-sales-admin** | `*` (все операции) для pods, pods/log, pods/exec, pods/portforward, deployments, replicasets, daemonsets, statefulsets, services, endpoints, configmaps, secrets, ingresses, persistentvolumeclaims, jobs, cronjobs. `get`, `list`, `watch` для events, roles, rolebindings. Действует **только в неймспейсе `sales`**. | Функциональная команда домена «Продажи» (владелец продукта, DevOps-инженер домена) — управление ресурсами своего домена. |
| **domain-zhku-admin** | `*` (все операции) для pods, pods/log, pods/exec, pods/portforward, deployments, replicasets, daemonsets, statefulsets, services, endpoints, configmaps, secrets, ingresses, persistentvolumeclaims, jobs, cronjobs. `get`, `list`, `watch` для events, roles, rolebindings. Действует **только в неймспейсе `zhku`**. | Функциональная команда домена «ЖКУ» (владелец продукта, DevOps-инженер домена) — управление ресурсами своего домена. |
